# Archived experiment artifacts

These files are retained for auditability but are not the canonical evidence
used by the current paper.

- `failed/`: incomplete runs, failed controls, or superseded tolerance checks.
- `smoke/`: reduced-size protocol validation runs.
- `superseded/`: successful earlier artifacts replaced by a later complete run.
- `exploratory/`: completed studies excluded from the current paper's evidence.

Canonical full-run artifacts remain directly under `experiments/results/`.
