# Code of conduct

We want technical disagreement here to be rigorous, direct, and safe for the
people doing the work.

Participants must:

- critique claims, evidence, and code rather than people;
- disclose uncertainty, failed controls, and conflicts of interest;
- avoid harassment, threats, discrimination, doxxing, and sexualized conduct;
- protect credentials, private datasets, embargoed research, and vulnerability
  reports; and
- respect maintainers' decisions about evidence thresholds and project scope.

Unacceptable behavior may be removed and participation may be restricted. Use
the private contact path in [`SECURITY.md`](SECURITY.md), including
[ryan@sekos.ai](mailto:ryan@sekos.ai) when GitHub private reporting is
unavailable, for sensitive conduct reports; do not post personal details in a
public issue.
